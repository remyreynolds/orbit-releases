# Orbit

A living desktop for macOS and Windows: a moving 8K wallpaper plus your tasks, calendar, mail,
music and classes in one glass panel.

**Download:** https://remyreynolds.github.io/orbit-releases/ or the [latest release](https://github.com/remyreynolds/orbit-releases/releases/latest).

This repository hosts the website and the installers. Wallpaper photo credits are listed on the site.
